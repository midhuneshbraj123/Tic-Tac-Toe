Tic Tac Toe

A simple, interactive web-based Tic Tac Toe game played against a bot opponent.

Description:

This project is a classic 3x3 Tic Tac Toe game built using basic web technologies (HTML, CSS, and Vanilla JavaScript). The player takes turns as "X" against an automated bot opponent that plays as "O". The bot includes logic to block winning moves, complete its own winning sequences, and make tactical choices (such as prioritizing the center grid spot). The app features a dark-themed visual layout and offers immediate game outcome feedback along with a quick reset button to restart matches instantly.

Getting Started:

Dependencies
Operating System: Any modern operating system (Windows, macOS, Linux, Android, iOS)
Web Browser: Any standard browser (e.g., Google Chrome, Mozilla Firefox, Microsoft Edge, Safari)
Software: No additional software or special dependencies required.

Installing:

Download Source Files:
Clone or download the project folder containing the following files:
index.html
style.css
script.js
File Modifications:
No file configuration or directory changes are needed. Keep all three files together in the same folder.

Executing Program:

Follow these steps to run the game:
Locate the index.html file in your project folder.
Double-click index.html to open it in your default web browser (or right-click and choose Open With -> your browser of choice).
Click any empty square on the grid to make your move as "X".
The bot will automatically respond with its move as "O".
To start a new game at any time, click the Play Again button below the board.

Help:

Issue: Buttons or styles look broken.
Solution: Make sure index.html, style.css, and script.js are stored in the exact same directory folder.
Issue: Game logic or clicks are not working.
Solution: Ensure JavaScript is enabled in your web browser settings.
