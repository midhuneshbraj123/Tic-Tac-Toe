# Tic Tac Toe vs Bot

A simple Tic Tac Toe game built with HTML, CSS, and JavaScript where a human player (X) plays against an easy computer bot (O).

## How to Play
1. Open `index.html` in any web browser.
2. Click any empty box on the grid to place your **X**.
3. The bot will automatically take its turn and place an **O**.
4. Get three in a row horizontally, vertically, or diagonally to win!
5. Click the **Reset** button to start a new game.

## Technologies Used
* **HTML5** for the game layout
* **CSS3** for styling the board and buttons
* **JavaScript** for the game logic and bot turns
